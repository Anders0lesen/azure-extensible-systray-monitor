# Bundled Tabler icons

These SVG files are vendored from [Tabler Icons](https://tabler.io/icons) version `3.46.0` and are bundled with the application. Runtime network access is never required to render them.

The files preserve Tabler's 24 x 24 view box, 2 px outline stroke, and `currentColor` styling. Add only icons actually used by the product, record the source version here, and retain `LICENSE.txt` when updating them.
