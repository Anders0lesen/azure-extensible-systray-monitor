# Azure Health Beacon v0.4.0

Download **AzureHealthBeacon-Setup-v0.4.0.exe** below and run it. Existing installations update in place. This is a per-user Windows 11 installation and does not request administrator access.

## What changed

- Add Resource Graph/KQL findings checks across all enabled subscriptions available to the login.
- Include templates for active alerts, Resource Health, Service Health, and Azure Policy non-compliance.
- Add a native KQL editor with live test-before-apply safety.
- Add default-off Windows-start and start-minimized settings.
- Make approved manual updates silent, in place, and self-restarting.
- Show “Fully up to date” beside the update button instead of opening a separate dialog.

## Security notes

- No credential or token fields were added. Azure authentication still uses Microsoft interactive login and the Beacon's isolated Azure CLI profile.
- KQL is sent only to Azure's read-only Resource Graph endpoint. It is never executed locally.
- Imported rules remain disabled until reviewed, successfully tested, and explicitly applied.
- Graph query text and finding names may reveal internal Azure metadata even though rule packs contain no credentials.

The installer is not Authenticode-signed yet. Verify the accompanying SHA-256 checksum and GitHub artifact attestation before installation.
