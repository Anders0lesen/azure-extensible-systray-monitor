# Azure Health Beacon 0.7.0

This release replaces the old Tk windows with the modern Windows 11 shell from the approved redesign mockup. It remains dark by default, adds light mode, uses one navigable application window, and keeps the tray icon strictly operational.

## The new check workflow

- **Add a check** first shows all six signal sources with nothing preselected.
- Resource, workspace, and metric discovery live inside the relevant configuration page.
- Resource Graph and Logs/Application Insights expose a proper KQL editor.
- Rules can be renamed and edited.
- **Save and enable** remains unavailable until the exact unsaved draft returns a reachable live result.

The six source types remain provisioning state, VM power state, constrained resource property, Resource Graph, Logs/Application Insights, and Azure Monitor metric. These are query surfaces rather than a fixed catalogue of Azure products, so users can express VM, Key Vault, networking, AVD, container, Functions, database, and application-specific conditions using the signal Azure actually exposes.

## Security and upgrades

The established Python Azure/rule engine now runs as a private child process behind anonymous pipes and a fixed data-only command set. Credentials and tokens never enter the Windows UI. Existing local configuration and credential isolation remain in place, including the non-configurable 14-day hard deletion.

The installer upgrades 0.6.0 in place, installs the self-contained Windows shell plus its private engine, and restarts the app. Update downloads remain pinned to this repository and require both published SHA-256 sources to agree.

This is still an unsigned public preview. Windows may show **Unknown publisher**; verify the published SHA-256 checksum and GitHub build-provenance attestation.
