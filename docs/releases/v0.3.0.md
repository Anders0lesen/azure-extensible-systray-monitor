## Install

Download **AzureHealthBeacon-Setup-v0.3.0.exe** below and run it. This is a per-user Windows 11 installation and does not request administrator access.

> This public-preview installer is not Authenticode code-signed yet. Windows may show an Unknown publisher warning. Verify the SHA-256 file or the GitHub build attestation before running it.

## What changed

- Added a normal Windows installer, Start Menu entry, version metadata, and Add/Remove Programs registration.
- Added the Azure Health Beacon brand icon to the installer, executable, shortcuts, app windows, Installed apps, and README.
- Added **Check for updates** inside the tray app.
- Added manual, notify-only, and automatic update modes.
- Kept background checks and automatic installation off by default; automatic installation requires explicit confirmation.
- Pinned updates to this exact GitHub repository and exact release asset naming.
- Required the GitHub-provided SHA-256 digest and the published checksum file to agree before installation.
- Added GitHub build provenance attestation for the installer.

Azure credentials, rules, and the isolated Azure CLI profile are not placed in the installer or updater request.

The tray icon remains a dedicated operational status signal and is not replaced by the brand artwork.
