# Azure Health Beacon v0.5.0

Download **AzureHealthBeacon-Setup-v0.5.0.exe** below and run it. Existing installations update silently in place after approval, then restart. This is a per-user Windows 11 installation and does not request administrator access.

## What changed

- Replace the cramped check editor with a dark-first **Rule Studio**; switch to light mode from the top-right toggle.
- Browse the Log Analytics workspaces and tables, Azure resources, and metric definitions visible to the signed-in identity.
- Create full Azure Monitor Logs/Application Insights KQL rules where returned rows are findings.
- Create Azure Monitor metric rules with configurable lookback, aggregation, reducer, dimension filter, comparison, and threshold.
- Edit and rename existing rules, with a fresh live test required before saving changes.
- Start from transparent examples for Application Insights, AVD, Azure Functions, containers, alerts, health, and policy—or write your own query.
- Open the public GitHub repository directly from the new About window.

## Security notes

- No credential, password, token, client-secret, or query-result field was added.
- Azure operations still use Microsoft's interactive sign-in and the Beacon-owned isolated Azure CLI profile with its fixed 14-day deletion boundary.
- Log query output is capped before it returns to the app. At most 25 compact finding previews remain in memory; they are never logged, saved, or exported.
- Signal discovery reads metadata only and is not persisted.
- Imported rules remain disabled until reviewed, successfully tested, and explicitly enabled.

The installer is not Authenticode-signed yet. Verify the accompanying SHA-256 checksum and GitHub artifact attestation before installation.
